# NETRUN // RED V1 release notes

V1 is the Cardputer ADV Netrunning simulator release candidate. It provides:

- Scenario JSON loading from SD with Schema Version 1, branching Architectures,
  stable references, and mixed Floors.
- Homebrew/user-defined Black ICE catalogs with visual and animation selection,
  including FIRE plus direct damage.
- Enemy Netrunner catalogs and baseline, defensive, and sentry behavior profiles.
- LATCH, WARDEN, and CROWN plus Custom Demon catalogs with independent visual and
  animation presentation.
- Player Black ICE and bounded multi-ICE encounters.
- The fully offline Web Scenario Builder with validation, graph editing, previews,
  JSON import/export, and browser-local workspace persistence.

Distribution: source available under the PolyForm Noncommercial License 1.0.0. Non-commercial use, modification, forks, and redistribution are permitted under that license; commercial rights are not granted.

Current limitations include one active Demon runtime, no CYD/touch port, no wireless
Scenario transfer, and no save/resume. A V1.0.0 tag and public release package are
not created until the exact release candidate passes the final Cardputer ADV
hardware regression.
